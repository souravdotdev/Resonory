RESONORY LOGO KIT  -  Resurfacing mark
=========================================

COLOURS
  Charcoal      #141414   RGB 20 20 20       symbol lines, wordmark
  Burnt orange  #D4621A   RGB 212 98 26      the cue dot only
  Off-white     #FAFAF7   RGB 250 250 247    light background / lines on dark

VARIANTS (in every logo folder)
  full-colour-on-light   charcoal + orange, for off-white or light backgrounds
  full-colour-on-dark    off-white + orange, for charcoal or dark backgrounds
  one-colour-charcoal    single ink, light backgrounds
  one-colour-white       single ink, dark backgrounds or photography

  The two light-coloured variants (full-colour-on-dark, one-colour-white) are
  delivered on a #141414 background in SVG, PDF, EPS, PNG and JPG so they are
  visible in any viewer. Transparent copies are in each folder's Transparent/
  subfolder for placing over your own dark designs.

FORMATS
  SVG  master vector, filled shapes only, wordmark converted to outlines (web, Figma)
  PDF  vector for print and documents
  EPS  vector for legacy print workflows and signage vendors
  PNG  transparent background (dark/white variants sit on charcoal), sizes in the file name (px = width for the symbol, height for lockups)
  JPG  flattened on its intended background (slides, docs, places without transparency)

FOLDERS
  01-Symbol             the mark on its 48-unit grid (includes 4-unit padding)
  02-Horizontal-Lockup  symbol + wordmark side by side
  03-Stacked-Lockup     symbol above wordmark
  04-App-Icon           rounded tile, plus an unmasked square for stores that mask icons themselves;
                        64 px and below use the heavier small-size cut
  05-Favicon            favicon.ico (16/32/48), adaptive favicon.svg (switches for dark mode),
                        PNGs, apple-touch-icon, Android icons, site.webmanifest, head-snippet.html

USAGE
  Clear space: one dot diameter on every side.
  Below 24 px use the favicon / small-size files.
  Don't recolour, stretch, rotate, add effects, or move the dot.

Wordmark: Inter Display Medium (SIL Open Font License), converted to outlines.
